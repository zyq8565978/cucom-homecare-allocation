# Code availability

The Python code for the allocation models, paired cluster resampling, resource accounting and figure generation is publicly available at https://github.com/zyq8565978/cucom-homecare-allocation. The repository includes software dependencies, reproduction instructions and disclosure-controlled aggregate results. Public scripts reproduce the reported tables and figures from these aggregates; participant-level re-analysis requires authorised CHARLS data prepared according to the documented analytical schema. Original code is released under the MIT licence.
