# Version 1.0.0

Publication release of the frozen two-policy CHARLS cost–consequence analysis and final aggregate exhibit data.

- Cohort, weights, priority rules, capacity grid, estimates, uncertainty and adverse results are unchanged.
- Analysis modules are separated from local workspace dependencies; private input/output locations are supplied explicitly.
- Public reproduction is distinct from restricted participant-level re-analysis.
- Original 2018/2020 point calculations and selected paired-draw replays were checked against the frozen arrays. Validation scope and maximum numerical discrepancy are recorded in `metadata/PORTABILITY_VALIDATION.json`.
- Aggregate arithmetic, source selection, suppression and exact display reconstruction are checked by the public verification scripts.
- The frozen analysis had 5,000 paired draws for each clustering approximation. Publication-port validation is not a new statistical analysis and does not claim to have independently rerun all original participant-level preprocessing.
- Earlier rule development and the shift to a 500-programme reference were result-informed. This release is not a prospective registration and does not erase the earlier analyses.

This release contains code and aggregate data, not a submitted manuscript, clinical endorsement, or a claim that S1-R universally outperforms S0-R. No raw participant data are included.
